# BA Advisory Desk

BA Advisory Desk is a client-facing service app for senior business analysis advisory work.

It includes:

- public website
- pricing and sample work
- support center and custom advisory discovery scheduling link
- client login
- client profile
- request intake
- file upload
- client dashboard
- admin operations view
- Bid & Proposal Response Automation controlled access service line
- Response Engine package intake, credit tracking, and worker handoff
- Advisory Credit tracking
- Stripe checkout API route
- Stripe webhook route
- Supabase credit ledger foundation
- low-credit reminder route
- AI indexing support through `llms.txt`

See [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) for Vercel, Stripe, Supabase, and domain setup.
